# 5.46 の再提出と優先審査の依頼（2026-09-15、コピー用）

配信中の 5.43 と審査待ちの 5.45 は、`flight.js` が同梱されておらず、操縦操作の出題・解説の「動きで見る」・見え方の「動きで見る」・3D シミュレーターが動かない（`dev/docs/internal-design.md` の v05.46 の節）。
直した 5.46 を出し、Apple に優先審査（Expedited App Review）を頼む。上から順に行う。

## 1. App Store Connect で 5.45 を取り下げ、5.46 で再提出

https://appstoreconnect.apple.com → マイ App → 航空学生 適性検査トレーニング（Apple ID 6808281696）

1. iOS のバージョン 5.45 が「審査待ち（Waiting for Review）」なら、右上の「審査から取り下げ」（提出物の「提出をキャンセル」）を押す。状態が「デベロッパにより却下済み」になる。
   - **5.45 が先に「審査通過」になっていたら**: 同じ不具合を持つので**配信しない**。自動リリースの設定なら配信されてしまうので、通ったのに気づいた時点で 5.46 の提出を急ぎ、5.46 を上に重ねる。まだ通っていないなら取り下げが最も確実。
2. その版の画面で、バージョンの欄を **5.46** に書き換えて「保存」（新しいバージョンを作ってもよいが、書き換えのほうが掲載文とスクリーンショットをそのまま使える）。
3. Codemagic（https://codemagic.io）→ アプリ `kokuteki-trainer` → Builds → 「Start new build」→ branch **main**（v05.46 が入っていること）、workflow **TENRYU iOS（App Store）** → Start。約 3〜4 分でアップロード。
4. App Store Connect の TestFlight の一覧で、ビルドの処理が終わるのを待つ（5〜10 分。「処理中」→「終了」）。
5. **TestFlight で実機に入れ、操縦操作の出題・解説の「動きで見る」・見え方の「動きで見る」・3D シミュレーターが動くことを確かめる**（今回の不具合がここで見つかるはずだった）。
6. バージョン 5.46 の画面 → 「ビルド」→ 古いビルド（57）があれば行の「削除」→「ビルドを追加」→ **ビルド 58**（Codemagic #58）を選ぶ →「完了」→「保存」。
7. 「このバージョンの最新情報」を下の文に差し替えて「保存」。
8. 「審査用に追加」→「審査へ提出」。「1 項目が提出されました」と出れば審査待ち。
9. 続けて「2. 優先審査の依頼」。

ASC の癖（2026-09-14〜15 に分かったもの）: 開いた直後はキー入力が効かないことがある。押せないときはページを開き直す。保存は押してから 10〜20 秒で灰色になる。

### 「このバージョンの最新情報」（5.46）

```
操縦操作の出題と解説の「動きで見る」、見え方の「動きで見る」、3D シミュレーターが動かなかった不具合を直しました（アプリに同梱するファイルが 1 つ欠けていました。通信や端末の設定は関係ありません）。
・アプリでは「新しい版が出ています」の帯を出さず、お知らせは同梱のものを表示します。通信の設定はなくしました。
・解説の「動きで見る」に、見え方の一覧と同じ HUD の十字を出します。
・記録の削除は 1 つのボタンで全種目まとめて行います。
```

## 2. 優先審査の依頼（Expedited App Review）

提出のあとに出す（提出前だと「審査中の提出物がない」で受け付けられない）。

https://developer.apple.com/contact/app-store/?topic=expedite （Apple Developer のアカウントでサインイン）

| 欄 | 入れる値 |
|---|---|
| App Name | 航空学生 適性検査トレーニング |
| Apple ID (App ID) | 6808281696 |
| Platform | iOS |
| Version Number | 5.46 |
| Reason | **Critical bug fix** |
| Explanation / Details | 下の英文をそのまま貼る |

### 貼る英文

```
The version currently on the App Store (5.43; 5.45, which had the same defect, has been removed from review) has a packaging defect: a required JavaScript file (flight.js, the app's flight model) was omitted from the app bundle by our build script. As a result, the app's core feature does not work at all: the control-operation questions (both practice and timed test), their explanations, the "see it move" animations, and the 3D simulator. Users see a frozen instrument image or an error message. Every customer of this paid app is affected, and there is no workaround on the user's side.

Version 5.46 fixes this. The change only adds the missing file to the bundle and adds a check to the build script so that a missing file stops the build. No other functionality or behavior has changed.

The app exists to prepare candidates for the Japan Air Self-Defense Force Aviation Student entrance examination. The first-stage examination period ends on September 26, 2026, so our users have days, not weeks. We would be very grateful for an expedited review of version 5.46. Thank you.
```

Steps to reproduce を聞かれたら:

```
1. Install version 5.43 from the App Store on any iPhone or iPad.
2. Open the app, choose the "control operation" (操縦操作) category and start the practice or the timed test.
3. The question never appears; the attitude-indicator image stays frozen.
4. Alternatively open the 3D simulator or "see it move" in an explanation: an error message is shown and nothing loads.
```

## 3. 5.46 が配信されたあと

- [ ] App Store で 5.46 が「配信準備完了」→ 配信中になったことを確かめる（`https://itunes.apple.com/lookup?id=6808281696&country=jp` の `version` が 5.46）。
- [ ] 実機で App Store から更新し、操縦操作・「動きで見る」・シミュレーターが動くことを確かめる。
- [ ] `guide.html` の iOS 版の不具合の帯を外す（アプリの `news.json` のお知らせ n-20260915-ios は残してよい。日付つきの記録になる）。
- [ ] `languageCodesISO2A` が `["JA"]` になっているか（v05.44 の Info.plist の直しが初めて配信される）。
- [ ] App Store Connect の「価格および配信状況」で、9 月 27 日に 1,000 円へ変える**価格のスケジュールを削除**し、価格が 3,000 円になっていることを確かめる（5.46 の提出とは別の作業。審査は要らない）。
