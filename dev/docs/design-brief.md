# Claude Design 発注草案 — 航空適性トレーナー UI/UX

作成日: 2026-09-02　状態: 草案（発注前レビュー用）

## 1. 依頼概要

航空学生の適性検査対策アプリ「航空適性トレーナー」の UI/UX デザインを依頼します。
ロジック（出題・採点・計器の描画）は実装済みの前提で、画面レイアウト・配色・タイポグラフィ・コンポーネント仕様を納品してください。

- 対象: 高校生〜20代前半の受験者。主にスマートフォンで使い、ホーム画面に追加した PWA として起動する。PC は副次。
- 設計順序: スマートフォン（縦持ち）を第一に設計し、PC 幅は拡張として扱う。
- 使い方: 1問あたり数秒〜十数秒で答える反復練習。1セッションで数十問。
- 世界観: コックピットの計器盤。暗い盤面に計器が浮かぶ夜間飛行の雰囲気を第一候補とするが、ライトテーマも必須。

## 2. 納品物

1. デザインカンバス（主要画面のアートボード）
   - 種目1「方位」画面（スマートフォン / PC）
   - 種目2「姿勢指示器」画面（スマートフォン）
   - 種目1+2「複合」画面（スマートフォン）
   - 種目3「操縦操作」画面（スマートフォン / PC）
   - フィードバック状態（正解・不正解）の例（スマートフォン）
   - ホーム画面追加の案内バナー、PWA 起動時（ブラウザ UI なし）のヘッダー
2. デザイントークン一覧（CSS 変数名は §5 の名前で固定）
3. コンポーネント仕様（状態ごとの見た目、余白、角丸、フォントサイズ）

## 3. 画面構成

共通シェル:
- ヘッダー: アプリ名、現在の種目の記録（出題数・正解数・正答率・平均解答時間・連続正解）
- 種目タブ: 4つ（1. 方位 / 2. 姿勢指示器 / 1+2. 複合 / 3. 操縦操作）。各タブに1行の説明
- 本文: 左が問題カード、右が「設定」「解き方のメモ」「記録」の3カード。狭い画面では縦積み

問題カード共通:
- 問題番号、経過タイマー（0.1秒刻み）、問題文
- 図（種目により1〜3点）、回答部、フィードバック部（正誤、解答秒、解説、「次の問題」ボタン）

種目別の回答部:
- 方位: 8方位ボタンを 3×3 の方位配置に並べる。中央は空き
- 姿勢指示器: 姿勢指示器の絵が入った選択肢4つ（A〜D）
- 複合: 姿勢指示器＋方位指示器の2連パネルが入った選択肢4つ
- 操縦操作: 3枚の視界を縦に並べる。区間「①→②」「②→③」それぞれに操作ボタン6つ（操縦桿 右/左/奥/手前、ヨー 右/左）。最後に「回答する」

## 4. コンポーネントと状態

| コンポーネント | 状態 |
|---|---|
| 種目タブ | 通常 / ホバー / 選択中 |
| 回答ボタン（方位・4択・操作） | 通常 / ホバー / 選択中 / 正解 / 不正解 / 非活性（薄く） |
| 主ボタン（回答する・次の問題） | 通常 / ホバー / 非活性 |
| 統計チップ | 数値は等幅フォント |
| 設定行 | セレクト / チェックボックス |
| フィードバック | 正解（緑系）/ 不正解（赤系）の見出し、解説リスト |
| 図のキャプション | 「後方から見た図」「前方から見た図」など。強調語を含む |

## 5. トークン（名前固定・値はデザイン側で決定）

| 変数 | 用途 |
|---|---|
| `--bg` `--panel` `--panel2` `--line` `--line2` | 地・パネル・罫線 |
| `--text` `--muted` `--faint` | 文字 3段階 |
| `--accent` | 強調・選択・計器の機体シンボル |
| `--sky` `--earth` | 計器と視界の空・地面。ダーク/ライトで判読性を保つこと |
| `--ok` `--bad` | 正解・不正解 |
| `--display` `--body` `--mono` | 見出し・本文（日本語）・数値のフォント |

ライト/ダーク両テーマの値を納品。文字コントラストは 4.5:1 以上。

## 6. 制約

- 計器・機体・視界の絵はロジック側が SVG で動的に生成し、親要素の幅いっぱいに広がる。寸法はピクセルではなく割合で指定すること（例: 方位図は画面幅の 80%、選択肢内の計器は選択肢幅の 70%）。縦横比は 方位図 1:1、第三者視点 360:250、姿勢指示器・方位指示器 1:1、視界 3:2。
- すべての寸法・余白・文字サイズは `%`・`rem`・`vw`・`fr` で指定し、`px` を使わない。
- タップ領域は最低 2.75rem 四方。片手操作を想定し、回答ボタンは画面下寄りに置く。
- スマートフォンのセーフエリア（ノッチ・ホームバー）を考慮する。
- アイコン（タブ・操作ボタン・UI）は RIKYU AI が別途納品する線画アイコンを使う。24px グリッド、`currentColor`。
- 日本語本文フォントは Google Fonts で入手できるものに限定。
- 動きは最小限。正誤の表示は即時に読めることを優先し、演出で遅らせない。
- `prefers-reduced-motion` を尊重。

## 7. 実コピー（サンプル）

- 問題文（方位）: 「上から見下ろした戦闘機が向いている方位を、8方位から答えてください。」
- 問題文（操縦）: 「コックピットから見た外の様子が①→②→③の順に変化しました。各区間で行われた操作を選んでください。」
- 正解表示: 「正解 ✓」 / 不正解: 「不正解 ✗」
- 解説例: 「水平線がだんだん右上がりに傾く → 右にロール → 操縦桿を右。」
