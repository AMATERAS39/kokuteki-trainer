# 平均回答時間を、紹介ページに出す

紹介ページ（`/guide`）の札に出す「平均回答時間」は、**合言葉つきで開いた端末の記録**を映したものです。
web 版で計測が 1 回終わるたびに、その端末の種目ごとの合計（問数・正解数・合計の解答時間）を送り、紹介ページはそれを読んで札の数字を入れ替えます。

## 仕組み

| もの | 役割 |
|---|---|
| `worker.js` | `GET /api/avg` で数値を返し、`POST /api/avg` で置き換える。合言葉の SHA-256 が合うときだけ受け取る |
| Cloudflare KV | 置き場所。鍵は `avg` の 1 つだけ |
| `index.html` の `checkRec` / `sendRec` | `/?rec=…` で開いた端末に合言葉を残し、計測が終わるたびに送る |
| `guide.html` の末尾の script | `/api/avg` を読んで札を入れ替える。読めなければ既定の持ち時間のまま |

合言葉そのものはリポジトリに書きません。`worker.js` にあるのは SHA-256 だけです。
合言葉を持たない端末は何も送らず、送り先も合言葉が合わなければ受け取りません。

## 用意するもの（1 回だけ）

1. Cloudflare のダッシュボード → **Storage & Databases → KV** → **Create a namespace**。
   名前は `kokuteki-stats` など。作ると **Namespace ID**（32 桁の英数字）が出るので控える。
2. `wrangler.jsonc` に次の 3 か所を足す（`main` と `assets.binding` と `kv_namespaces`）。

```jsonc
{
  "name": "kokuteki-trainer",
  "compatibility_date": "2026-09-02",
  "main": "worker.js",
  "observability": { "enabled": true },
  "workers_dev": true,
  "assets": { "directory": "./", "binding": "ASSETS" },
  "kv_namespaces": [{ "binding": "STATS", "id": "ここに Namespace ID" }],
  "routes": [
    { "pattern": "kokuteki.amaterasu-vocab.com", "custom_domain": true },
    { "pattern": "kokuteki.amaterasu-vocab.com/*", "zone_name": "amaterasu-vocab.com" }
  ]
}
```

3. push すると、これまでどおり自動で配信されます。`https://kokuteki.amaterasu-vocab.com/api/avg` を開いて
   `{"stats":null}` が返れば動いています。

## 記録を送る端末にする

合言葉つきの URL を 1 回開くだけです。

```
https://kokuteki.amaterasu-vocab.com/?rec=（合言葉）
```

合言葉は端末に残り、URL からは消えます。以後、計測が終わるたびに自動で送ります。
やめるときは、その端末で `localStorage.removeItem('aat.rec')` を実行します。

## 気をつけること

- **静的ファイルの配信は変わりません**。`main` を足しても、ファイルのある道は今までどおり静的配信が受け持ち、
  Worker が呼ばれるのは `/api/avg` のような、ファイルの無い道だけです。
- 送るのは合計だけで、いつ解いたかは送りません。KV には最後に送られた数値が 1 つ残るだけです。
- 紹介ページは、読めなければ**既定の持ち時間**（5 / 10 / 15 / 20 秒）と、その旨の小見出しに戻ります。
  数字が入ると、小見出しが「平均回答時間」に変わります。
