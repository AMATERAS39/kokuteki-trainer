# 航空適性トレーナー 内部設計書

作成日: 2026-09-02　版: 1.0（確定版）

## 1. 目的と構成

航空学生の適性検査（方位判断・姿勢指示器の読み取り・操縦操作の判断）を反復練習する単一ページのブラウザアプリ。
ロジック（出題生成・採点・計器の描画）と見た目（配色・タイポグラフィ・レイアウト）を分離する。

| 層 | 担当 | 成果物 |
|---|---|---|
| ロジック層 | 本設計（コード） | `engine.js` 相当。出題・採点・計器 SVG の生成 |
| 見た目層 | Claude Design に発注 | 画面レイアウト、配色トークン、コンポーネント仕様 |
| アイコン | RIKYU AI に発注 | モードタブ・操作ボタン・方位ボタン等の幾何学アイコン |

ロジック層は CSS 変数（トークン）だけを参照し、色の実値は持たない。見た目層はトークンの値とレイアウトを決める。

## 2. 種目（モード）

| ID | 名称 | 出題 | 回答形式 |
|---|---|---|---|
| `heading` | 1. 方位 | 上面図の戦闘機 + 北マーク | 8方位から1つ |
| `attitude` | 2. 姿勢指示器 | 第三者視点の戦闘機 | 姿勢指示器の4択 |
| `combo` | 1+2. 複合 | 上面図 + 第三者視点 | 姿勢指示器+方位指示器の計器パネル4択 |
| `control` | 3. 操縦操作 | コックピット視界3枚（縦に時系列） | 各区間の操作を6種から選択 |

## 3. 座標と符号の規約

- 方位 heading: 北を 0°、時計回りに正。8方位は 45° 刻み（N=0, NE=45, …, NW=315）。
- バンク bank: 右バンク（右翼が下がる）を正 [°]。
- ピッチ pitch: 機首上げを正 [°]。
- ヨー yaw: 機首が右へ振れる向きを正 [°]。
- 画面角 theta: 画面の上を 0°、時計回りに正。上面図の機体は `rotate(theta)` で描く。
- 北マーク角 phi: 画面の上を 0°、時計回りに正。`heading = (theta − phi) mod 360`。

### 見え方の規約（採点の根拠）

| 機体の動き | 姿勢指示器 | コックピット視界 |
|---|---|---|
| 右バンク | 水平線が右上がり（地面が右で高い） | 景色が左に傾く（水平線が反時計回りに回る） |
| 左バンク | 水平線が左上がり | 景色が右に傾く |
| 機首上げ | 水平線が下がり、空が広がる | 水平線が下がる |
| 機首下げ | 水平線が上がり、地面が広がる | 水平線が上がる |
| 機首右（ヨー） | 方位指示器のみ変化 | 水平線は不変、景色が左へ流れる |
| 機首左（ヨー） | 方位指示器のみ変化 | 景色が右へ流れる |

SVG 実装: 姿勢指示器・視界ともに `rotate(−bank) translate(0, pitch·k)` を地平線グループに適用し、ヨーは地平線上の目印グループを `translate(−yaw·k, 0)` する。

## 4. 出題生成

### 4.1 方位 `genHeading`

- `dir` ∈ 1..7 を一様乱数（`dir = 0` ＝機首が N マークと同じ向き＝答えが自明なので出題しない）。
- 設定「N マークの向き」: 既定はランダムで、8 方位（`phi` ∈ {0,45,…,315}）のいずれか。「上に固定」なら `phi = 0`。
- `theta = phi + dir·45`。
- 正解: `dir`。

### 4.2 姿勢指示器 `genAttitude`（2026-09-02 改訂: 14 方向イラスト方式）

第三者視点は「南からの固定視点」。ブルーインパルスは原点にあり、機首が向く 14 方向のイラスト（ユーザー提供の向き図から切り出し）を 1 枚提示する。

| 方向 | heading | pitch | 方向 | heading | pitch |
|---|---|---|---|---|---|
| 北 | 0 | 0 | 北東上 / 北東下 | 45 | +30 / −30 |
| 南 | 180 | 0 | 北西上 / 北西下 | 315 | +30 / −30 |
| 東 | 90 | 0 | 南東上 / 南東下 | 135 | +30 / −30 |
| 西 | 270 | 0 | 南西上 / 南西下 | 225 | +30 / −30 |
| 上 | なし | +90 | 下 | なし | −90 |

- 読み方: 画面の奥が北、手前が南、右が東、左が西。翼は常に水平（バンク 0）。真下は背面がこちら（南）を向く。
- 図版の生成（最終）: ユーザー提供の 3D モデル `T4blue.fbx`（`t4model/`）を three.js で描画する（`render/render.html` + `tools/render_server.py`）。
  - 座標系: x＝東（右）、y＝北（紙面奥）、z＝上。カメラは南 (0,−d,0) から原点を見る。
  - モデル固有軸（機首 −z、上 +y）を `ax=90`（X 軸回り +90°）で標準状態（機首 +y、上 +z）に合わせる。
  - 方位 h・ピッチ p への姿勢: `R = Rz(−h) · Rx(p)`。斜め方向は h ∈ {45,135,225,315}、p = ±30°（`?dp=` で変更可。45° は急すぎるとの指摘で 30° に決定）。
  - 脚・前脚・開状態のエアブレーキのメッシュは非表示（`ladder` はラダー＝方向舵なので表示する）。脚を隠すと脚収納部の内側（無地材質 `main`）が灰色の板として見えるので、`?paint=main/main/006ab0` で機体下面の青に塗って閉じた蓋に見せる。背景は透明（アプリ側で明るいグレー #cdd3da を敷く）。
  - 材質は両面描画（片面だと垂直尾翼などの薄い面が欠ける）。法線は形状から再計算する（元データの内向き法線が黒い陰影の原因だった）。照明は環境光主体（hemi 2.2 / amb 0.6 / dir 0.9）。
  - 1800×1200 で描画し、14 枚を共通の切り出し枠でトリミングして縮尺を揃え、減色せず WebP（品質 92・透明あり）で `app/img/bi-*.webp` に保存。上面図は `t4-top.webp`。
  - 幾何学的な帰結: 北東下・北西下は腹面が少し見え、南東下・南西下は機首が手前に来るため上面（キャノピー）が見える。
- 旧方式（Gemini 生成の向き図の切り出し `tools/cut_bi14.py`）は保持のみ。
- 正解の姿勢指示器: バンク 0、上表のピッチ。
- 誤答候補: ピッチ反転、バンク ±30 を付けたもの、水平（または ±30）。真上・真下は ±90 と ±30・0 のピッチ違いのみ（バンク違いは見分けにくいため）。
- 選択肢 4 つをシャッフル。

### 4.3 複合 `genCombo`

- 14 方向のうち方位が定まる 12 方向から 1 つ選ぶ。上面図は表示しない（方位もイラストから読む）。
- 誤答候補: `(h+180) (360−h) (h±90) (h±45)` の方位違い、`−pitch` のピッチ違い、バンク ±30、およびその組み合わせ。
- 選択肢は姿勢指示器 + 方位指示器の組で表示。

### 4.4 操縦操作 `genControl`

操作は次の6種のみ。同時操作はなく、複数操作は一つずつ順に行う。

| ID | 表示 | 機体 | 状態変化 |
|---|---|---|---|
| `stick-right` | 操縦桿 右 | 右に傾く | bank += 20 |
| `stick-left` | 操縦桿 左 | 左に傾く | bank −= 20 |
| `stick-forward` | 操縦桿 奥 | 沈む（機首下げ） | pitch −= 8 |
| `stick-back` | 操縦桿 手前 | 上昇（機首上げ） | pitch += 8 |
| `rudder-right` | ヨー 右 | 水平のまま右を向く | yaw += 10 |
| `rudder-left` | ヨー 左 | 水平のまま左を向く | yaw −= 10 |

- 写真は3枚。①が開始状態、①→② と ②→③ の2区間それぞれに操作1つが対応する。
- 設定「操作数」: 単一操作（2区間とも同じ操作を継続）/ 2操作（区間ごとに独立に抽選。同じ操作や逆操作も許す）。
- 設定「①の初期姿勢」: 水平（bank=pitch=yaw=0）/ ランダム（bank∈{−30,−15,0,15,30}, pitch∈{−10,0,10}, yaw∈{−10,0,10}）。
- フレーム: `frames[0] = init`, `frames[t] = frames[t−1] + effect(ops[t−1])`。
- 回答（2026-09-02 改訂）: 操作列を文にした 4 択。「操縦桿を右に倒し、右方向舵を踏む」のように①→②、②→③の順で連用形でつなぐ。単一操作は「操縦桿を右に倒す」。
- 誤答候補: 順序の入れ替え、片方または両方を逆操作にしたもの、片方を別の操作にしたもの、同じ操作の繰り返し。
- 採点: 選んだ選択肢が正解列と一致すれば正解。解説は区間ごとに見え方→機体の動き→操作を示す。
- 表示: 3枚を縦に並べ、①②③のラベルを付ける。

## 5. 描画関数（ロジック層が提供）

すべて純関数で SVG 文字列を返す。SVG は `viewBox` と `width="100%"`（`aspect-ratio` 付き）で出力し、実寸は親要素の幅で決まる。ピクセル指定は行わない。色は CSS 変数。

| 関数 | 引数 | 縦横比 | 内容 |
|---|---|---|---|
| `figTopDown(theta, phi)` | 画面角, 北角 | 1:1 | 方位環 + N マーク + **T-4 上面図イラスト**（`img/t4-top.png`、元絵は機首左向きなので `rotate(theta+90)`） |
| `figDir14(d)` | 14 方向の要素 | 346:148 | **南からの固定視点イラスト**（`img/bi-<id>.jpg`）+ 上/北/東の凡例。ラベル部分は空の色で塗り潰し済み |
| `svgTopDown(theta, phi)` | 画面角, 北角 | 1:1 | （旧）シルエット版。未使用 |
| `svg3D(bank, pitch, front)` | 姿勢, 視点 | 360:250 | （旧）簡易3Dモデル。未使用 |
| `svgAI(bank, pitch)` | 姿勢 | 1:1 | 姿勢指示器。機体シンボル固定、地平線が動く。ピッチ目盛 ±10/20/30、バンク目盛 0/10/20/30/45/60 |
| `svgHI(heading)` | 方位 | 1:1 | 方位指示器。カードが `rotate(−heading)`、N/3/6/E/… の表記 |
| `svgCockpit(bank, pitch, yaw, progress)` | 姿勢+ヨー+前進度 | 3:2 | 風防クリップ内に空・地面・水平線・目印（太陽、山並み、雪山、塔）、固定 HUD。`progress` 0..1 で目印を最大 1.45 倍に拡大（時間が進むと前進して景色が大きく見える）。出題の①②③は 0 / 0.5 / 1 |

3D モデルの視点: 後方は方位角 26°・仰角 18° から見下ろす。前方視点は機体を 180° ヨーさせて同じカメラで描く。

## 6. 状態と永続化

```
state = { mode, question, qcount, answered, t0 }
settings = { north, ops, init, auto, qLimit: 秒(0=なし), sLimit: 秒(0=なし), qCount: 問(0=なし), dirLabel: kanji|alpha, skipExplain, showIntro, showPractice, theme, version }
hideIntro = { <mode>: true }   // 「次回から表示しない」
stats[mode] = { n, c, t }   // 出題数, 正解数, 合計秒
```

- `localStorage` キー `aat.settings`, `aat.stats`, `aat.mode`。読み書きは try/catch で保護。
- タイマーは出題描画完了で開始、回答確定で停止し、秒を stats に加算。

## 7. 画面遷移と操作

画面は 3 つで、URL のハッシュで切り替える（ブラウザの戻るが効く）。

| ハッシュ | 画面 | 内容 |
|---|---|---|
| `#home`（既定） | ホーム | タイトル「パイロット適性検査トレーニング」と種目カード 4 枚（種目名のみ: 方位／姿勢指示器／方位×姿勢指示器／操縦操作）。右上のメニュー（ホーム／アプリの説明） |
| `#train/<mode>` | 訓練 | 1 種目 = 1 セッション。種目タブはなく途中で切り替えられない。離れるときは確認ダイアログ。制限時間つき（下記） |
| `#settings` | 設定 | 制限時間（1 問あたり: なし/5〜60 秒、種目全体: なし/1〜15 分）、方位の表記（漢字 / アルファベット）、テーマ、出題設定（北の向き・操作数・初期姿勢・自動で次へ） |
| `#about` | 説明 | 箇条書きで簡潔に: アプリの説明、種目、視点と座標、計器と操作、**3D ビューア**、クレジット |

3D ビューア（`viewer.js`、three.js を CDN の importmap で読み込み、説明画面を開いたときだけ動的 import）:
- モデルは `model/t4.glb`（描画ツールの `?export=1` で FBX から変換。脚・開状態エアブレーキを除去、収納部を機体色で塗り、頂点共有化、テクスチャ 1024px、約 4MB）。
- 世界座標は描画ツールと同じ（x 東・y 北・z 上）。カメラは南 (0,−24,0) から原点。OrbitControls でドラッグ回転・ピンチ拡大、パンは無効。
- 14 方向ボタンで `R = Rz(−h)·Rx(p)` の姿勢へ 0.45 秒で補間。「視点を南に戻す」でカメラを初期位置へ。
- 水平面の格子（z=−6）と東（赤）・北（緑）・上（青）の矢印を表示。
- 画面を離れると描画ループを止め、戻ると再開。読み込み失敗時は文言で通知。

セッションと制限時間:
- 1 問の制限時間があるときはカウントダウン表示（残り 3 秒で赤）。0 になると「時間切れ ✗」として不正解扱いで採点し、正解を強調して解説を出す。
- 種目全体の制限時間があるときは種目バー右に残り時間（残り 30 秒で赤）。0 になると回答中なら即終了、回答済みなら「結果を見る」に切り替わり、成績（出題・正解・正答率・平均解答時間）と「もう一度」「ホームへ」を表示する。
- 既定値（本番はスピード勝負）: アルファベット表記、20 問、1 問 5 秒、全体 5 分、解説スキップ。設定に version を持ち、版が変わったら既定値に戻す。
- 解説スキップ: 計測中は正誤の印を 0.45 秒だけ見せて次へ。練習問題では常に解説を表示。
- 出題数: 10/20/30/50/制限なし。達したら終了して成績を表示。

開始の流れ（`enterMode`）:
1. 操縦操作だけは先に「練習／計測」を選ぶ（`#train/control/practice` | `#train/control/measure`）。
2. 説明画面（種目ごとの箇条書き + 制限時間の要約 + 「次回から表示しない」チェック、既定でオン）。設定「開始時の説明を表示」をオフ→オンにすると再表示。
3. 練習 3 問（制限時間なし・解説あり・記録に含めない。設定で非表示可。操縦操作では出さない）。
4. 計測（制限時間・出題数つき）→ 成績。

操縦操作の「操作ごとの見え方」（`#train/control/gallery`）: 操縦桿（左・右・奥・手前の 1 行、排他）と方向舵（左・右、排他）をボタンで選ぶ。操縦桿は一度に 1 方向しか倒せないので、複合パターンは操縦桿＋方向舵の組み合わせだけ。複数選択時は「同時に行う／順番に行う」を切り替え可。順番に行うときは「操縦桿 → 方向舵」「方向舵 → 操縦桿」で先に行う側を選ぶ（順番で結果が変わるため）。選んだ操作の水平①→②→③を縦に並べて表示し、操作ごとの見え方の説明を添える。目印として雪山の頂と塔の先端にオレンジの輪、①の水平線の位置に破線を描く（`svgCockpit` の第 5 引数 `marks`）。未選択でも水平飛行の 3 枚を出し、条件で出る行は薄くするだけで消さないため、選択しても画面がずれない。さらに選択行と 3 枚を 1 画面に収める（スクロール不要）ため、`body[data-phase="gallery"]` で記録チップ・脇のメモ・冒頭説明を隠し、フレームは風防部分だけ（viewBox 360×188 に差し替え）を `calc((100dvh - 31.5rem)/3)` の高さで表示する。375×667 でも収まることを確認済み。

操縦操作の練習（シミュレータ）: 視界と姿勢指示器を表示し、操縦桿（奥/左/右/手前）と方向舵（左/右）のボタンを押している間だけ姿勢が変わる（バンク 45°/s、ピッチ 18°/s、ヨー 25°/s、上限 ±60/±40/±120°）。SVG の `.ck-att` `.ck-yaw` `.ai-h` `.ai-p` の transform を書き換えて更新する。前進の表現として目印の拡大率を 8 秒周期で 1→1.45 倍に変化させる。

1. ホームで種目を選ぶ → セッション開始 → 新規出題。
2. 回答 → 採点 → フィードバック（正誤、経過秒、解説、正解の強調）→「次の問題」。
3. 設定変更は即座に新規出題。設定「正解したら自動で次へ」が ON なら正解時 1.4 秒後に自動出題。

キーボード: 方位はテンキー 8/9/6/3/2/1/4/7（または w/e/d/c/x/z/a/q）、4択は 1〜4、操縦操作は各区間の 1〜6、Enter で回答/次へ。

## 9. 配信形態: PWA（スマートフォン主体）

主な利用端末はスマートフォン。ホーム画面に追加してアプリとして起動できる PWA として配信する。

| ファイル | 役割 |
|---|---|
| `manifest.webmanifest` | 名称、`display: standalone`、縦向き固定、テーマ色、アイコン 192/512（maskable） |
| `sw.js` | サービスワーカー。初回に全ファイルをキャッシュし、以後はキャッシュ優先でオフライン動作。更新時は `CACHE` の版数を上げる |
| `icons/*.png` | アプリアイコン。現在は仮生成品。正式版は RIKYU AI の納品で置き換える |
| `index.html` の meta | `viewport-fit=cover`、`theme-color`、iOS 用 `apple-mobile-web-app-*` と `apple-touch-icon` |

- Android/Chrome: `beforeinstallprompt` を受けて「ホーム画面に追加」ボタンを表示。
- iOS/Safari: 自動インストール不可のため、共有メニューからの追加手順を案内する。
- 配信は HTTPS の静的ホスティング（GitHub Pages 等）。サービスワーカーは HTTPS か localhost でのみ動く。
- 寸法はすべて `%`・`rem`・`vw`・`fr` で指定し、`px` は使わない。タップ領域は最低 2.75rem。
- セーフエリア（ノッチ）は `env(safe-area-inset-*)` で確保する。

## 背景の昼／夜（設定 `scene`）

- 設定 `scene: 'auto' | 'day' | 'night'`（既定 `auto`）。`applyScene()` が `body[data-scene]` を付け、`auto` は判定時刻で 5〜7 時を日の出 `dawn`、7〜17 時を昼 `day`、17〜19 時を夕焼け `dusk`、それ以外を夜 `night` とする（手動は昼／夜のみ）。出題の `render()`、シミュレーター開始、見え方の表示、設定変更時に判定し直す。
- 適用範囲: 姿勢指示器・方位×姿勢指示器の機体画像の背景（`.d14` の `--d14bg`）と、操縦操作の視界 `svgCockpit`（出題・練習・シミュレーター・見え方すべて）。姿勢指示器の計器そのものや方位の上面図は変えない。
- `svgCockpit` の色は CSS 変数 `--ck-sky / --ck-earth / --ck-sun / --ck-mtn / --ck-mtn2 / --ck-snow / --ck-star` で差し替える（昼は既定色、夜は `body[data-scene="night"]` で定義）。空は `--ck-sky-top`（上）から `--ck-sky-hz`（水平線）への縦グラデーション（回転する群の中なので水平線に沿う）で、日の出は上が藍・水平線が橙、夕焼けは上が紫・水平線が赤橙、昼は上が明るい青・水平線が薄い水色（テーマの暗めの `--sky` は使わない。暗いと夜と区別がつかない）、夜は単色。星は固定座標 70 個を常に描き、昼は `--ck-star: none` で見えない。太陽は夜には月色になる。

## スマホ幅は 1 画面に収める（スクロール不要）

- `@media (max-width:63.99rem)` で、ホームと訓練画面の `body` を `height:100dvh` の縦 flex にし、`.app` → `#view-*` → `.layout` → `.card` → `#quiz` / `#sim` → `#figs` … と `flex:1; min-height:0` を連ねて、図（機体画像 `.d14`、上面図 `.fig.top`、視界 `.frame .v` / `.sim .view`）だけが画面の余りに合わせて伸縮する。図には最小高さ（6rem／3.5rem）があり、それ以下の画面では少しだけスクロールする。
- 訓練画面では脇のメモ・記録（`aside`）を出さず、出題・練習・シミュレーター中は成績チップ（`.stats`）も隠す。出題文は 1 行に短縮。選択肢の計器は `clamp(5rem, 14dvh, 7.5rem)`（複合は `10dvh`）で高さ基準。
- 視界 SVG は `ckCompact()` で風防部分だけ（viewBox 360×188）にしてから描く（出題・練習・見え方で共通）。
- 375×812 と 375×667 の全画面（ホーム／方位／姿勢／複合／操縦操作の出題・練習・見え方・選択）でスクロールが出ないことを確認済み。設定とアプリの説明はフォーム・3D ビューアなのでスクロール可のまま。

## 操縦操作の練習シミュレーター（3D、`app/sim3d.js`）

- three.js（importmap の `three`、viewer.js と同じ CDN）。`mount(container,{onState,view})` が描画器・世界・機体を作り、`{input:{x,y,r}, state, setView, level, home, dispose}` を返す。`index.html` の `startSim()` が UI（HUD、視点ボタン、計器、操縦桿、方向舵）を組み、`import('./sim3d.js?v=N')` で読み込む。
- 世界: x=東 y=北 z=上（m）。±1500 m の四角い空間で、境界は半透明の赤い格子の壁（`LIMIT`）。地面は 100 m ごとの格子（500 m ごとに太線）、原点に南北の滑走路、民家 260・木 320・塔 6（インスタンス描画、滑走路の帯は空ける）、山は見え方を学ぶために空間の中の近くに置く（開始位置の正面左に雪山、正面右に塔、ほかに中くらいの山を散らし、壁の外に遠景の環）。夜は月明かりとして青白い光を強めにし、地面・山の色も明るめに寄せる。昼夜の配色は `--ck-*` の CSS 変数から取り、空は縦グラデーションの球、夜は星。霧は 900〜4600 m。
- 機体: 速度 60 m/s 固定。入力 1 のとき ロール 60°/s、ピッチ 25°/s、ヨー（方向舵）20°/s。バンクで協調旋回（g·tan(b)/v、±30°/s まで）。バンク ±80°、ピッチ ±60°。地面（z=3）で止まり、機首下げは 0 に戻す。壁に当たると `state.wall` が立ち HUD に「壁です」を出す。向きの行列は R = Rz(−h)·Rx(p)·Ry(b)。
- 視点: 一人称（機首位置のカメラ、FOV 72）と三人称（後方 32 m・上 10 m から追従、機体 GLB を表示、FOV 55）。操縦席視点は利用者の指示で廃止。選択は `aat.simView` に保存。高度の手がかりに地面の影と垂線を描く。
- 操作: 左に操縦桿（円の中でドラッグ。上 = 奥 = 機首下げ、右 = 右バンク。離すと中央）、右に方向舵ボタン（押している間）。それぞれ pointerId を別に持つので両手で同時に操作できる。キーボードは矢印が操縦桿、A/D（, .）が方向舵。
- 計器: 視界の下の行に姿勢指示器と方位指示器。`svgHI` の回転部に `.hi-c` を付けて毎フレーム回す。HUD 左上に 高度／方位／バンク／ピッチ。

## 姿勢のバンク出題（2026-09-02 追加）

- 姿勢指示器・方位×姿勢指示器で、真上・真下を除く 12 方向にバンク 0 / ±30° / ±60° を付けて出題する（`pickBank`、水平が 1/3）。設定 `bank`（既定 `on`、`off` で水平のみ）。
- 機体画像は `render.html?banks=30,60&…` で 14 方向 + 12 方向 × r30/l30/r60/l60 を一括描画し、`tools/postprocess_bank.py` で共通の枠（62 枚の外接矩形 + 40px）に切り出して WebP にする。ファイル名は `bi-<方向>-r30.webp` など（r = 右バンク）。`figDir14(d, bank)` が選ぶ。エンブレム `bi-logo.png` は処理対象から除外すること（巻き込むと枠が壊れる）。
- 右バンク = 機首の向きに対して右翼が下がる。南からの固定視点では、機首がこちら（南）を向くほど左右が逆に見える。解説文はこの点を必ず添える。
- 誤答候補: 左右逆のバンク、水平、大きさ違い（30↔60）、ピッチ違い、その組み合わせ。
- 解説（`.fb.show`）が出ているときは 1 画面レイアウトの伸縮をやめて通常の流れに戻す（`:has(.fb.show)`）。図がつぶれて選択肢に重なるのを防ぐ。

## UI 整理（2026-09-03）

- ヘッダーは全画面で「ホームボタン（左）・タイトル（中央）・メニュー（右）」を常時表示。メニューの「ホーム」項目は廃止。ホームアイコンは暫定の線画（`#i-home`）。RIKYU に正式なアイコンを発注済み（プロジェクト c33b0941…、デザイン「発注: ホームボタンのアイコン」）。届いたら `#i-home` の path を差し替える。
- 成績チップ（`.stats`）は訓練画面だけ。ホームのモードカードに「平均 x.x 秒（n 問）」を表示（`stats[m]`）。
- 設定は 3 群のみ: 計測（出題数・1 問の制限時間・全体の制限時間）、表示（方位の表記 アルファベット／漢字、テーマ 自動／ダーク／ライト、背景 自動／昼／夜）、説明と練習（「もう一度表示する」ボタン = hideIntro を全消去）。
- 固定した出題条件（`GEN`）: N マークはランダム、操縦操作は 2 操作、①の初期姿勢はランダム、バンクあり。計測中は解説を出さず 450 ms で自動的に次へ（旧 skipExplain / auto は撤去）。
- 開始時の流れ: 説明（「次回からこの説明と練習を表示しない」既定チェック）→ 練習 3 問（解説あり）→ 計測。チェック済みなら直接計測。`#train/<mode>/practice` で説明を飛ばして練習から始められる（アプリの説明ページの「練習する」ボタン）。操縦操作は従来どおり 選択 → 練習（3D）／計測。
- アプリの説明ページは図入り: 南からの視点図（`figDir14`）、姿勢の例 3 つ（機首上げ／下げ／右バンク + 対応する姿勢指示器）、方位指示器、上面図、6 操作それぞれの視界（`svgCockpit` に目印つき）、練習ボタン、3D ビューア。`renderAbout()` が一度だけ組み立てる。
