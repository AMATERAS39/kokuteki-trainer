# テスター交換コミュニティへの投稿文

貼る前に埋めるもの（4 つ）:

- 【GROUP】: Google グループの URL（Play Console → テスト → クローズドテスト → テスターの「Google グループ」）
- 【OPTIN】: オプトイン用の Web リンク（同じ画面の「Web でのオプトイン」）
- 【PKG】: パッケージ名（例: com.amaterasuvocab.kokuteki）
- 【MAIL】: 連絡用のメールアドレス（テスターの Gmail を受け取る先）

有料アプリなので、テスターには**ライセンステスト**で無料にする。Play Console → 設定 → ライセンス テスト で「Google グループ」を選び、`tenryu-testers@googlegroups.com` を入れておく。
こうするとグループに参加した人が自動でライセンス テスターになるので、Gmail を 1 人ずつ受け取る必要がない。
「無料で入れられる」と書くには、この設定を先に済ませておくこと。秘密の鍵や解除コードは書かない。

```
**How to join (about 1 minute):**
1. Join the Google Group: 【GROUP】
2. Opt in: 【OPTIN】
3. Install from Google Play (the app is paid, but everyone in the group is on the license-test list, so it is free for testers).
4. Keep it installed for 14 days. You don't have to use it every day.

**Package:** 【PKG】

If the install still shows a price, wait a few minutes after joining the group and reload the Play Store page; ping me if it persists.
Thanks — and post your link, I'll return the favor.
```

返信のひな形（相手のアプリに入ったあと）:

```
Joined the group, opted in and installed. I'll keep it for 14+ days. Here's mine if you can return it: 【OPTIN】 (group: 【GROUP】). Thanks!
```

## 気をつけること

- 相互テストは「入れて 14 日置く」だけで成り立つ。互いのアプリを実際に使う義務はないが、レビューの依頼はしない（Play の規約に触れる）。
- 有料の代行（「テスター 12 人 ○ドル」）は使わない。規約上の不正扱いを受けることがある。
- Google グループを「誰でも参加できる」設定にしておく（承認制だと相手が待たされて離脱する）。
- 12 人そろってから 14 日。途中で 1 人抜けると数え直しになるので、13〜15 人集めておく。
