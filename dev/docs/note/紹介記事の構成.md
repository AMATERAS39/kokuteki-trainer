# note のアプリ紹介ページ 構成案

この記事のねらいは 3 つ。上から順に優先する。

1. 受験生に中身が伝わり、その場で Web 版（体験版）を触ってもらう
2. クローズドテストのテスター（Android・12 人）に応募してもらう
3. 非公式の学習アプリなので、誠実さで信頼を作る

読み手は 航空学生を受験する高校生・高専生・大学生と、その保護者。次に 航空ファンと個人開発に関心のある人。

### タイトル（候補）

- 適性検査は速さの勝負。だから制限時間つきで解けるアプリを作った

「航空学生」「適性検査」「アプリ」の 3 語をタイトルに入れる（検索で見つかる語）。

### リード（3〜4 行、見出しなし）

### 1. 適性検査で何が問われるか
4 種目を 1 つずつ、スクリーンショット 1 枚 + 2〜3 行で。読み方のコツを 1 行添えると、記事だけでも役に立つ。

| 種目 | 画像 | 添える一行 |
|---|---|---|

### 2. 本番は速さの勝負（設計の話）
- 1 問ごとの制限時間と全体の制限時間を、種目ごとに開始前に決められる
- Easy / Normal / Hard。Hard は補助の表示が減る
- 記録（出題数・正答率・平均解答時間）は端末の中だけに残る
- ここは長く書かない。3〜4 行 + 画像 1 枚

### 3. 操縦操作は「体で覚える」（ここが記事の山）
- 3D シミュレーターで自分で操縦桿と方向舵を握れる。一人称・三人称・地上からの 4 視点
- 一人称には HUD（水平線とピッチの目盛り）が出る
- 「操作 → 見え方」の対応が体に入ると、選択肢を読む速さが変わる
- 画像: `screenshots/06_シミュレーター.png` と `screenshots/07_見え方.png`
- 「見え方」の画面では、初期状態と操作を選ぶと ①→②→③ の視界が並び、そのまま動きでも確認できる

### 4. 展示飛行が見られる（記事のつかみ・SNS で伸びる部分）
- 自動演目 16 課目。編隊を組み、スモークを引き、地上に立って見上げられる
- 目玉: キューピッド（2 機がハートを描き、1 機が矢のように貫く）、スタークロス（5 機が直線で五芒星を描く）、クリスマスツリー・ローパス（タイヤを出し、ライトを点けて頭上を抜ける）
- 画像: `images/cupid.png`（ハート）、`images/star.png`（星）
- アプリの中のカメラボタンで、操作ボタンの写らない写真が撮れる。読者の投稿を促す一行を添える

### 5. 使い方（3 ステップ）
1. 種目を選ぶ 2. 練習（制限時間なし・解説つき）3. 計測（制限時間つき）
- 画像は不要。箇条書き 3 行

### 6. 約束していること
- 買い切り・広告なし・アカウント登録なし
- 一度開けばオフラインでも動く（3D も含めて端末に持つ）
- 記録は端末の中だけ。個人情報を集めない

### 7. 【テスター募集】Android をお使いの方へ
記事の中で一番はっきり書く。ここが今の目的なので、見出しを太字級に。
- お願いしたいこと: 参加リンクを開いて「テスターになる」を押し、インストールして 2 週間そのままにする（毎日使う必要はない）
- 条件: Android 端末と、Play にログインしている Google アカウント
- お礼: 全機能版を無料で。感想をもらえたら直す
- 参加リンク（Play Console のクローズドテストのウェブリンクを貼る）
- 連絡先: アプリ内の「ご要望・お問い合わせ」か、note のコメント

### 8. これは非公式の学習アプリです
- 試験の出題形式や採点基準を保証するものではない
- 機体の 3D モデル: 航空自衛隊アクロバットチーム T-4ブルーインパルス（3Dえいじくん 様）https://eiji-mappa.booth.pm/items/3328542

## note で書くときの実務メモ

- 段落は 2〜3 行で改行。note は行間が広いので、長い段落は読まれない
- 見出し（大見出し・小見出し）を使うと目次が自動でつく。上の 1〜10 をそのまま見出しにする
- 全体 2,000〜3,000 字、画像 8 枚前後。画像は横長（1200 px 幅）で用意する
- GIF は貼れない。動きを見せたいなら YouTube に短い動画を上げて埋め込む
- ハッシュタグ: #航空学生 #自衛隊 #適性検査 #個人開発 #ブルーインパルス #PWA
- 価格や公開時期は「予定」と明記する（審査中に確定と書くと、ずれたときに信用を落とす）
- 記事を公開したら、X に「1 枚の画像 + 一文 + リンク」で流す。伸びるのは ハート／星の画像
