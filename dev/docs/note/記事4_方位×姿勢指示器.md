3 つ目の種目では、同じ 1 枚の絵から方位と姿勢の両方を読みます。
答えるのは、姿勢指示器と方位指示器の組み合わせです。

【画像: play/screenshots/04_方位×姿勢指示器.png】

## 読むものが 2 つある

絵そのものは、方位の問題と姿勢指示器の問題で見てきたものと変わりません。
変わるのは、1 枚から 2 つを読み取って、その組み合わせを選ぶところです。

読むものが増えるぶん、人によって時間の差が出ます。
差がつくのは、絵を見てから「どちらを先に読むか」を毎回決めているときです。

## 順番を決めておく

先に方位を読みます。
N マークの位置を見て、時計回りに数えます。

次に上下を読みます。
機首が上がっているか下がっているか、そして左右の傾きです。

この順で固定しておけば、絵が変わっても手順は変わりません。
**選択肢は、方位が合っていても姿勢が違うものが混ざります。**
片方だけで選ばず、2 つとも読んでから選びます。

## 方位指示器の読み方

方位指示器は、いま向いている方位が上に来ます。
北を向いていれば N が上、東を向いていれば N は左に来ます。

機体の絵から読んだ方位と、指示器の上に来ている方位が一致するかを見ます。
指示器の中の N の位置から逆に読むほうが速い人もいるので、自分に合うほうで固定します。

1 問の持ち時間の目安は 15 秒です。
